# 外部仓库说明

`repositories/` 用来存放 Bio Studio 挂载的第三方能力源码，不是主工作区的核心开发面。

## 目录职责

- `active/`：当前启用、可被工作区调用的外部仓库
- `archived/`：归档或退役的外部仓库

## 当前 active 仓库

- `RFdiffusion`
- `evo2`
- `Biomni`
- `litefold/source`

## 使用原则

- 如果你的目标是“使用这些能力”，优先在 `projects/`、`lib/`、`tools/scripts/`、`mcp-servers/` 层编排
- 不要默认把这里当作主开发目录
- 如果确实需要修改第三方仓库，请明确这是：
  - 临时本地 patch
  - 长期维护 fork
  - 准备回传上游的改动

## Git 说明

部分路径以 gitlink / submodule 形式记录在主仓库中。  
这意味着：
- 它们有自己的 Git 历史
- 主仓库只记录指针，不记录内部完整源码历史
- 本地改动应谨慎处理，避免误把外部工作树当成普通目录重构

当前主仓库默认将这些子模块视为“外部引擎工作树”：
- `git status` 在主仓默认忽略子模块内部的未提交改动
- 只有子模块指针变化才应被视为主仓需要处理的变更
- 如果你要检查外部引擎自己的改动，请进入对应目录单独运行 `git status`
